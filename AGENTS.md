# Architecture rules
- Keep Instagram package values and recommendation rules in one browser-safe module so cards, comparisons, and the Instagram quiz stay aligned without changing other platforms.
- Keep YouTube package values and recommendation rules in their own browser-safe module so the YouTube cards, comparison and quiz stay aligned without changing Instagram.
- Use a shared HowItWorks section for the home and platform pages so process imagery and layout stay consistent while platform wording can vary.
- Use the shared FinalCTA for closing calls to action on home and platform pages so the full-background photo layout and controls stay consistent.
